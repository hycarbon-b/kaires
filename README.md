# kaires

Three frontend sites for the Kaires product suite.

| Branch | Site | Port |
|--------|------|------|
| `app-site` | Consumer AI chat app | 5175 |
| `bp-site` | Business/partner landing | 5174 |
| `company-site` | Company marketing site | 5173 |

## Worktree setup

```bash
git worktree add ../kaires-app    app-site
git worktree add ../kaires-bp     bp-site
git worktree add ../kaires-company company-site
```
