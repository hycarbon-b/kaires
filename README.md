# KAIROS 商业计划书网站

面向投资人的融资BP演示页面。

## 技术栈

- React 19
- TypeScript
- Vite
- Tailwind CSS

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 内容结构

BP包含以下章节：

1. **概览** - 项目介绍和核心数据
2. **问题** - 市场痛点分析
3. **解决方案** - KAIROS双引擎战略
4. **市场** - 市场规模和竞争格局
5. **商业模式** - 收入来源和增长飞轮
6. **产品** - 产品矩阵和技术特色
7. **技术** - 技术架构和核心能力
8. **竞争优势** - 差异化优势分析
9. **路线图** - 发展计划和里程碑
10. **团队** - 核心团队和顾问
11. **财务** - 财务预测和资金使用
12. **融资** - 融资需求和投资亮点

## 定制说明

### 修改团队信息

编辑 `src/sections/Team.tsx`，填写实际的团队成员信息。

### 修改财务数据

编辑 `src/sections/Financial.tsx`，根据实际情况调整财务预测数据。

### 修改联系方式

编辑 `src/sections/Ask.tsx`，填写实际的联系方式。

### 调整融资金额

编辑 `src/sections/Ask.tsx`，修改融资金额和股权比例。

## 部署

```bash
# 构建
npm run build

# dist 目录包含构建后的静态文件
# 可以部署到任何静态托管服务（Vercel、Netlify、GitHub Pages等）
```

## 注意事项

⚠️ **机密文件**：此BP包含公司机密信息，请妥善保管，控制访问权限。

建议：
- 部署到私有服务器或需要密码保护的托管服务
- 使用域名加密（HTTPS）
- 定期更新财务数据和产品进展
- 针对不同投资人，可能需要调整内容侧重点
